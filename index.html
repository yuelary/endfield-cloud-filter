云终末地滤镜 · 安装

《云·终末地》网页版的画面滤镜：锐化 / 对比 S 曲线 / 饱和度 / 暗部提亮 / 色温
  1. 先装一个用户脚本管理器（任选一个）：
    Tampermonkey 或 脚本猫 ScriptCat 或 Violentmonkey（Edge / Chrome / Firefox 都行）
  2. 点下面的按钮装脚本 —— 管理器会弹出安装确认页，点「安装」：
    安装「云终末地滤镜」
  3. 进游戏（endfield.hypergryph.com/cloud 之类），右上角出现面板就是装好了。
用法：Alt+G 收起 / 展开面板 · 按住面板上的「按住对比」能看出开关前后的差别 · 参数按站点自动记忆。
全屏时面板不显示是正常的，滤镜仍然生效；游戏锁定鼠标时用 Alt+G。
装过之后会自动更新，不用再管。
要是面板在、画面却没变化：点面板里的「诊断」，把显示的内容提到 Issues 就行。
