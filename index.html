云终末地滤镜 · 安装

《明日方舟：终末地》网页云游戏的画面滤镜：锐化 / 对比 S 曲线 / 饱和度 / 暗部提亮 / 色温
  1. 先装一个用户脚本管理器（任选一个）：
    Tampermonkey 或 脚本猫 ScriptCat 或 Violentmonkey（Edge / Chrome / Firefox 都行）
  2. 点下面的按钮装脚本，管理器弹出确认页后点「安装」：
    安装「云终末地滤镜」
  3. 进游戏，右上角出现面板就是装好了。
用法：Alt+G 收起 / 展开 · 按住「按住对比」对比开关前后 · 参数按站点记忆。
全屏时面板不显示是正常的，滤镜仍然生效；游戏锁定鼠标时用 Alt+G。
装好后自动更新。
面板在、画面无变化时：点面板里的「诊断」，把显示内容提到 Issues。
非官方工具，与鹰角网络及《明日方舟：终末地》官方无关；一切以官方为准。
