**云终末地滤镜 —— 《云·终末地》网页版的画面滤镜**

装好后，游戏画面上会多一层可调的后期处理：锐化、对比、饱和度、暗部提亮、色温。
处理在浏览器本地完成，不经过服务器，不会额外增加延迟。

**功能**

- 五个可调参数：锐化、对比 S 曲线、饱和度、暗部提亮、色温
- 五个预设：默认 / 轻度 / 锐利 / 影院 / 夜间护眼
- 按住「按住对比」可以临时关掉滤镜，松开恢复，方便看开关前后的差别
- 面板可以收成一个小圆球，拖到不挡画面的位置，位置会记住
- 参数按站点保存，下次进游戏还是上次调好的那套

**支持**

《云·终末地》网页版（`*.hypergryph.com` / `*.hypergryph.net` / `*.hycdn.cn`）和 B站 视频页。
别的云游戏站，在脚本头部加一行 `@match` 就行。

**隐私**

不读取 cookie，不读取账号信息；不请求任何外部网络；默认不发送任何数据。

**两点说明**

全屏时面板不显示，但滤镜仍然生效，建议在窗口模式下调好参数再全屏。
游戏锁定鼠标时点不到面板，用 `Alt+G` 收起或展开。
