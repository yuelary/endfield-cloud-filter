🎮 **《云·终末地》网页版画质增强｜一键装，画面立刻不糊了**

画面发灰、边缘发糊、远处的树和房子像一团奶油？
**不是你的网** —— 是云游戏为了省带宽，把画面压软了。

这个脚本在你**自己浏览器里**给它补一层后处理：锐化 · 对比 S 曲线 · 饱和度 · 暗部提亮 · 色温。
**零延迟、不换显卡、不花钱、不用登录。**

**✅ 零延迟**
滤镜由合成器直接吃，不经过服务端、不重新编码、不多一帧。云游戏最怕的就是延迟，这条不能将就。

**✅ 连 canvas 渲染的画面也管（这是它和别家最大的区别）**
云游戏新的渲染路径是 WebCodecs 解码 → WebGL canvas 上屏，这时页面上可能压根没有在播的 `<video>`，
**只处理 `<video>` 的通用视频增强扩展，在这儿等于没装**。这个脚本两条路都覆盖。

**✅ 按住对比，一秒验证**
面板上有个「按住对比」：按住 = 临时关掉滤镜。有用没用，一眼的事，不用听我吹。

**✅ 悬浮球，不挡画面**
面板收起后变成一个小圆球，可拖到任意位置、位置记住，点一下展开。`Alt+G` 也行。

**✅ 参数按站点记忆 + 5 个预设**
默认 / 轻度 / 锐利 / 影院 / 夜间护眼。调好一次，下次进游戏还是你那套。

**✅ 零遥测，看得见的代码**
不读 cookie、不碰账号、无任何外链请求、默认零上报（连调试信息都不发）。
纯 SVG 滤镜实现，单文件 500 行，没有混淆、没有压缩 —— **欢迎自己翻一遍**。

**✅ 免费 + MIT 开源**

**支持**：《云·终末地》网页版（`*.hypergryph.com` / `*.hypergryph.net` / `*.hycdn.cn`）、B站 视频页。
别的云游戏站加一行 `@match` 就行。

**已知限制（先说清楚）**：全屏时面板看不见但滤镜照常生效（建议窗口模式调好再全屏）；不做放大/插帧（那会多一帧延迟，对云游戏是负收益）；不改码率、不降延迟。

仓库 / 反馈：<https://github.com/yuelary/endfield-cloud-filter>
