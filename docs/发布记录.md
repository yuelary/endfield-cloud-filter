## 环境备忘（这台机器上推送时要注意的）

- 用的是 **MinGit**（`C:\Users\yuelay\tools\mingit`）：**不带 ssh、也不带凭据管理器**，
  而系统配置里却写着 `credential.helper = manager`（指向不存在的程序）⇒ HTTPS 推送会**静默卡住**。
- 所以推送走 **SSH over 443**（22 端口在本地网络不通）：
  `~/.ssh/config` 里 `Host github.com` → `HostName ssh.github.com` / `Port 443`
- git 使用 Windows 自带 ssh：`core.sshCommand = C:/Windows/System32/OpenSSH/ssh.exe`
- HTTPS 直连还会因 schannel 吊销检查失败（`CRYPT_E_NO_REVOCATION_CHECK`）。
  已导出 Windows 根证书到 `C:\Users\yuelay\.dsh\certs\windows-roots.pem`，
  并在本仓库设了 `http.sslBackend=openssl` + `http.sslCAInfo` 指向它（仅本仓库生效）。
- 日常推送：`git push origin main && git push origin --tags`

## 首次发布时踩过并已修的坑（都在 AGENTS.md 里有记录）

1. `document.appendChild(svg)` 抛异常 ⇒ 文档级注入静默失效（游戏里完全没效果）
2. 只处理 `<video>` ⇒ 云游戏走 WebCodecs→canvas 时等于没装
3. 3×3 卷积锐化被 `[0,1]` 钳位吃掉 ⇒ 改用非锐化掩模
4. 批量替换大小写不敏感，把 `s.w` 误改成 `settings.w` ⇒ 画布失效（已加 CI 闸门防复发）
