# 云游戏滤镜（网页云游戏 · 类似 NVIDIA Freestyle）

**主方案 = 油猴脚本**（跑在你自己那个 Edge 里 ⇒ **不用登录任何东西、不用换浏览器**）。

## 装（两步，各一次）

1. **装油猴**：Edge 加载项商店搜 `Tampermonkey` → 安装（一次点击）。
2. **装脚本**：浏览器打开

   ```
   http://127.0.0.1:8899/%E4%BA%91%E6%B8%B8%E6%88%8F%E6%BB%A4%E9%95%9C.user.js
   ```

   Tampermonkey 会弹「安装此脚本」→ 点安装。
   （这个地址是我在本地起的一个只读静态服务，只服务这个文件夹；重启 dsh 后服务会停，
   到时候直接开文件也行：`F:\ds\cloudgame-filter\云游戏滤镜.user.js`）

装完打开云游戏页面（进游戏后）就会看到**右上角面板**：

- 5 个滑杆：锐化 / 饱和度 / 对比 S 曲线 / 暗部提亮 / 色温
- 5 个预设：默认 · 轻度 · 锐利 · 影院 · 夜间护眼
- **按住对比**：按住即临时关掉滤镜，一眼看出前后差异（专门解决"看不出区别"）
- **诊断**：打印运行时事实（video 在哪、多大、是否 WebRTC、滤镜有没有挂上）
- `Alt+G` 收起/展开（游戏锁鼠标时也能按）；参数**按站点记忆**

## 为什么是 SVG 滤镜、不是 WebGL

2026-10-16 读过云·终末地的前端包（`index.cda000.js`，副本在 `C:\Users\yuelay\.dsh\tmp\cloud-js\`）：

- 流是 **WebRTC MediaStream 直接绑在 `<video>.srcObject`**（`RTCPeerConnection`×4、`srcObject`×8，
  没有 `new MediaSource`），全包**没有** `requestMediaKeySystemAccess` / `widevine` / `playready` ⇒ 无 DRM
- 既然就是普通 `<video>`，SVG 滤镜由合成器直接吃：**零拷贝、零额外帧延迟**（云游戏最在意延迟）
- 站点自己也在用 CSS filter 调色（源码里有 `_currentColorEnhanceLevel`）⇒ 我们的规则带 `!important` 压过它

锐化用**非锐化掩模**（`feGaussianBlur` + `feComposite arithmetic`，等价 orig + amt·(orig − blur)），
不是 3×3 卷积 —— 卷积在亮画面上会被 [0,1] 裁切吃掉（实测锐度几乎不涨）。

## v1.1 修掉的三个真 bug（都是我自己的）

1. **`document.appendChild(svg)` 抛 `HierarchyRequestError`** —— 一个 Document 只允许一个元素子节点（`<html>`）。
   异常被 catch 吞掉，于是**文档级那套永远没建起来** ⇒ 进游戏后（video 在文档里）**完全没有滤镜**。
   这就是"进游戏看过、没啥用"的根因。现在挂到 `<head>` 上。
2. **shadow DOM 够不到**：CSS 选择器不进影子树，且 shadow 里的元素引用不到文档里的 `url(#filter)`。
   现在劫持 `attachShadow`，每个 shadow root 里单独放一份定义 + 规则。
3. **锐化被裁切吃掉**：3×3 卷积换成非锐化掩模（实测拉普拉斯方差从"不涨"变成 +15.7%）。

另外加了行内 `!important` 保险 + MutationObserver（云游戏换通道/重连会重建 `<video>`）。

## 备选方案（不用了，留着记录）

- **影子 Edge 配置**：`F:\ds\edge-cgprofile`（748 MB）+ 扩展 `ext\`。
  因为 Edge 136+ 不给默认配置开远程调试口，当时用"复制一份配置 + `--load-extension`"绕过。
  缺点就是**要单独登录一次**。桌面图标已删；这 748 MB 要删说一声。
- **现成的开源方案** [treeks12/video-enhancer](https://github.com/treeks12/video-enhancer)：
  FSR1/RAVU 放大 + RCAS 锐化 + 神经插帧（v0.0.71，2026-10-15 还在更新）。
  想要"放大/插帧"时值得试；但插帧必然多一帧延迟，云游戏里我默认不推荐开。
